# IELTS Storage Platform

A modern IELTS training dashboard with:

- 160 mock tests across Listening, Reading, Writing, and Speaking
- WPM typing trainer
- Progress dashboard
- AI tutor chat assistant
- Speaking coach panel and mascot design
- Responsive layout

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech stack

- React
- TypeScript
- Vite
- Custom CSS

## Notes

This is a polished front-end prototype designed to match the requested product direction. It includes demo data and interactive UI flows, ready to be connected to a real backend or Supabase data layer later.
